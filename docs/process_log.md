# Process Log

## Project Topic
KOSPI200 AI financial and stock analysis dashboard.

## Development Flow
1. Colab-based AI model development
2. Dataset construction using DART financial data, KRX stock data, and macro indicators
3. XGBoost-based 60-day return prediction model
4. Conversion from notebook-based workflow to Streamlit UI
5. Debugging and local execution on macOS
6. GitHub-based version control and documentation

## Lessons Learned
- Vibe coding accelerated the initial software development process.
- However, generated code required environment debugging, dependency management, and testing.
- Separating model logic and UI logic made the software easier to maintain.
- GitHub commit history helped show continuous development rather than last-minute work.
